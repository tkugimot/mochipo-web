## Please check this before contacting us

Thank you for using Time Rich. We receive inquiries from many of you, and we are sorry that we have not been able to reply promptly. To save you time, we have listed frequently asked questions and guidance below, and we would appreciate it if you could check them before contacting us.

Almost all inquiries about Time Rich concern problems caused by iOS. The Screen Time feature provided by iOS itself still seems to be unstable, and in most cases there is very little the Time Rich app can do. The only lasting fix is to wait for future iOS updates, so we appreciate your understanding.

## Frequently asked questions

### The apps I selected to block are not being blocked

This is caused by a bug in iOS Screen Time. Please try the following steps to see if the problem is resolved.

1. Update iOS to the latest version, or restart your iPhone
2. Update Time Rich to the latest version
3. Go to Settings → Screen Time → Apps with Screen Time Access, and turn off access for all apps, including Time Rich
4. Delete the Time Rich app, then reinstall it from the App Store
5. Select the apps you want to block again
6. Set up the blocks you want to use again

### Apps I did not select are being blocked

This is also caused by a bug in iOS Screen Time. Please try the same steps as for "The apps I selected to block are not being blocked."

### The app selection screen is blank and I cannot select apps

This is caused by an iOS bug. Close the app selection screen and open it again, and it should display normally. Relaunching Time Rich or restarting your iPhone may also help.

It happens especially when there is a lot of content to display, and most often when you choose a category with many items, such as "Other." In such cases, there are reports that the screen displayed normally after first selecting apps in other categories. Please try that as well.

Time Rich simply uses the features provided by iOS as they are, so there is very little we can do about it. It has happened to me many times, too, and each time I have been able to make my selection by reopening the screen.

### A block started even though I should not have reached my time limit

In most cases, you had actually reached the time limit, but the usage shown in your iPhone's analytics had not been updated yet.

Open Settings → Screen Time → See All App & Website Activity. The time shown next to "Last Updated" is the point up to which that day's usage of apps and categories is displayed. First, please check whether that time is recent.

If the behavior still seems wrong after checking this, please try the same steps as for "The apps I selected to block are not being blocked."

### I want to edit a Schedule Block

Swipe left on the schedule you set and a "Delete" button will appear. Tap it to delete the schedule, and then set up the Schedule Block again.
